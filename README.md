# Hemitech — Technology Solutions

Multi-page website for Hemitech, a technology and design studio brand.
Five pages (home, about, services, work, contact) built as a pure static
site — no frameworks, no build step.

## Highlights

- Responsive layout with a mobile hamburger navigation (vanilla JS)
- Animated hero with particle effects and mouse-tracking interaction
- Scroll-aware navbar and smooth-scroll anchor navigation
- Async contact-form handler
- Single shared stylesheet and script across all five pages

## Tech stack

HTML5 · CSS3 · Vanilla JavaScript (ES6+)

## View locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```
